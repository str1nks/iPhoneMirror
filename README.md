# iPhoneMirror

**Экран iPhone на ПК с Windows через AirPlay («Повтор экрана»)**

Приёмник AirPlay с интерфейсом в стиле Windows 11 (Fluent / Mica). Живёт в трее, стартует вместе с Windows и сам запускает приём.

## Как это работает

Зашифрованный поток AirPlay (FairPlay) принимает [UxPlay](https://github.com/FDH2/UxPlay). iPhoneMirror запускает `uxplay.exe` в фоне, передаёт ему настройки, показывает статус и журнал, а также берёт на себя всю рутину: автозапуск, трей, правила брандмауэра, перезапуск при сбое сети.

```
iPhone  ──AirPlay (Wi-Fi)──▶  uxplay.exe  ◀── запускает и настраивает ── iPhoneMirror (GUI)
```

## Возможности

- **Статус в реальном времени**: остановлено, ожидание iPhone, iPhone подключён, ошибка.
- **Имя ПК на iPhone**: то, как компьютер называется в списке «Повтор экрана».
- **Настройки трансляции**:
  - во весь экран;
  - низкая задержка (отключает ожидание синхронизации);
  - 60 кадров/с;
  - качество: 1080p, 1440p или 4K (HEVC, для новых iPhone).
- **«Сворачивание — на задний план»**: свёрнутое окно трансляции не замирает, и его продолжают видеть Discord и OBS.
- **Автозапуск с Windows** (запись в `HKCU\...\Run`, стартует сразу в трей) и **автоматический запуск приёма**.
- **Повторные попытки**: если сеть после включения ПК ещё не готова, приём перезапускается сам (до 5 раз с паузой 10 с).
- **Кнопка «Разрешить в брандмауэре»**: создаёт правила для `uxplay.exe` и mDNS (UDP 5353) и переключает сеть с «Общедоступной» на «Частную».
- **Работа в трее**: закрытие окна сворачивает программу в трей, выход через значок в трее.
- **Один экземпляр**: повторный запуск просто показывает уже работающее окно.
- **Журнал** вывода UxPlay прямо в окне.
- Светлая и тёмная тема, эффект Mica.

## Требования

- Windows 10/11 (эффект Mica доступен в Windows 11, в остальных системах используется обычный фон).
- iPhone и ПК в **одной Wi-Fi сети**.
- `uxplay.exe` вместе с библиотеками (инструкция ниже, всё собирается скриптами из репозитория).
- Для UxPlay 1.74+ дополнительно ничего не нужно, там встроенный mDNS. Для старых сборок установите [Bonjour](https://support.apple.com/kb/DL999).

## Быстрый старт

### 1. Получить `uxplay.exe`

Проще всего собрать его скриптом (нужен интернет, около 10–20 минут):

```bat
build_uxplay.bat
```

Скрипт сам установит [MSYS2](https://www.msys2.org) через `winget` (если его нет), поставит компилятор и GStreamer, соберёт UxPlay и положит его в `C:\msys64\ucrt64\bin\uxplay.exe`.

Затем сделайте портативную копию, которая работает без установленного MSYS2:

```bat
python make_portable.py
```

Скрипт скопирует `uxplay.exe`, все нужные DLL и плагины GStreamer в папку `uxplay\` рядом с программой.

> Если у вас уже есть готовый `uxplay.exe`, положите его рядом с программой или в папку `uxplay\`. Программа также найдёт его в `PATH` или в `C:\msys64\ucrt64\bin`.

### 2. Запустить программу

```bash
pip install -r requirements.txt
python airplay_mirror.py
```

Если какой-то из пакетов не установлен, при запуске из исходников скрипт доустановит его сам.

### 3. Подключить iPhone

1. Нажмите **«Запустить»** (или включите «Запускать приём автоматически»).
2. На iPhone откройте **Пункт управления → Повтор экрана**.
3. Выберите свой компьютер в списке.

## Сборка .exe

```bat
build_exe.bat
```

Скрипту нужны `icon.ico` и, при желании, папка `uxplay\` рядом с ним. Результат:

```
dist\iPhoneMirror\
├── iPhoneMirror.exe
├── icon.ico
└── uxplay\            скопируется, если была рядом
```

Сборка делается в режиме папки (не `--onefile`), поэтому **переносите папку `dist\iPhoneMirror` целиком**. При первом запуске собранного .exe автозапуск с Windows включается автоматически, выключить его можно переключателем в окне или в меню трея.

## Параметры UxPlay, которые использует программа

| Настройка в окне | Аргументы `uxplay.exe` |
| --- | --- |
| Имя на iPhone | `-n <имя> -nh` |
| Во весь экран | `-fs` |
| Низкая задержка | `-vsync no` |
| 60 кадров/с | `-fps 60` |
| Качество 1440p | `-s 2560x1440` |
| Качество 4K (HEVC) | `-h265` |

## Решение проблем

**iPhone не видит компьютер.** Нажмите «Разрешить в брандмауэре» (потребуются права администратора), проверьте, что оба устройства в одной сети, и перезапустите приём. Для старых сборок UxPlay установите Bonjour.

**В журнале «Не найдены DLL для uxplay.exe» (код `-1073741515`).** Выполните `python make_portable.py`, чтобы собрать все библиотеки рядом с программой, или установите MSYS2.

**Картинка замирает при сворачивании окна трансляции.** Включите переключатель «Сворачивание — на задний план».

**`uxplay.exe` не найден.** Программа откроет страницу проекта UxPlay. Соберите его через `build_uxplay.bat`.

## Состав репозитория

| Файл | Назначение |
| --- | --- |
| `airplay_mirror.py` | основное приложение (GUI, трей, автозапуск) |
| `build_uxplay.bat` | автоматическая сборка UxPlay через MSYS2 |
| `make_portable.py` | копирует `uxplay.exe` со всеми DLL и плагинами GStreamer в `uxplay\` |
| `build_exe.bat` | сборка `iPhoneMirror.exe` через PyInstaller |
| `requirements.txt` | Python-зависимости |
| `icon.ico` | значок приложения |
